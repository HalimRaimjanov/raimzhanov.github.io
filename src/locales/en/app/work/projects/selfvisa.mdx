## Overview

I developed a website for SelfVisa, a visa assistance company serving applicants for the United States and European countries. The site brings service information and consultation options into a clear, accessible structure.

## Scope

- **Service pages:** visa assistance, document preparation and interview guidance.
- **Customer information:** consultation options and frequently asked questions.
- **Responsive design:** layouts adapted for desktop and mobile screens.

## Implementation

The website uses HTML and CSS for page structure and responsive styling, with interactive elements to support navigation.

## Result

A central resource where applicants can review available services and find the next step in their application process.
