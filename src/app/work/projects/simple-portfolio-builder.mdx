## Overview

A personal portfolio built with Next.js and Once UI. It brings together professional experience, selected projects, technical articles and photographs.

## Structure

- **Project case studies:** concise descriptions of the work and implementation.
- **MDX content:** articles and project pages maintained as source files.
- **Reusable components:** a consistent interface across the site's sections.
