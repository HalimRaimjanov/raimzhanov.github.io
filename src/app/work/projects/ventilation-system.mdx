## Overview

I developed a website for a company supplying and installing ventilation systems. The site organizes product information and installation services for homeowners and business customers.

## Scope

- **Product catalogue:** product cards with specifications and pricing.
- **Service pages:** installation information and customer support.
- **Responsive design:** layouts for desktop and mobile devices.
- **Interactive elements:** navigation and animations implemented with jQuery.

## Implementation

HTML and CSS provide the page structure and styling. jQuery handles interactive elements, with attention to responsive layouts and animation performance.

## Result

A structured website that helps customers review ventilation products and understand the company's services.
